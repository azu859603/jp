开启：注册页标注「必须填写」，不填不能注册；关闭：标注「如无可不填」，不填则该会员没有上级。填写时都会校验邀请码是否存在
需要审核时，申请在「卖家管理」中处理
无需审核时，卖家发布商品后直接上架展示

订单自动处理

由定时任务执行，填 0 表示关闭对应功能

以下功能依赖服务器定时任务：php think order:timeout（每 5 分钟）、php think order:confirm（每小时）、php think order:remind（每天）。定时任务未运行时，前台访问会兜底触发一次，但不保证及时
小时
拍下后超过该时长未付款，自动取消订单，商品可重新上架
超时自动取消与买家主动取消待付款订单均按此规则处理
天
发货后超过该天数买家未确认，系统自动完成订单并结算给卖家
天
付款后超过该天数仍未发货，每天给卖家发一条站内信催发货

业务部门

显示在「关于我们」页面正文下方，内容为空则不显示该区块

格式：每个部门一段，段与段之间空一行。第一行是部门名称，之后每行「岗位：姓名 姓名」，姓名可留空只显示岗位。姓名太多可以换行接着写（不带冒号的行会并入上一岗位），全角空格、两字名中间的补位空格会自动整理。例如：
古代书画部
总经理：张三
业务经理：李四 王五
