# 拍卖平台使用说明

本文档面向三类使用者：前台会员（买家 / 卖家）、代理、平台管理员。文末附运维与命令行说明。

| 端 | 入口地址 | 登录账号 |
|---|---|---|
| 前台（会员端） | `/` | 前台会员账号（手机号 + 密码） |
| 代理端 | `/agent/login/index` | 前台会员账号，且在主后台被设为「代理」 |
| 主后台 | `/admin1314/login/index` | 管理员账号（后台「管理员管理」维护） |

三个端的登录页都有图形验证码，连续输错密码会临时锁定，稍等几分钟后再试。

## 一、前台（会员端）

### 1. 注册与登录

- **注册**：`/user/register`。填写手机号、密码，以及**邀请码（必填）**。邀请码是 8 位纯数字，由邀请人在「我的邀请」页面获取。填写谁的邀请码，谁就是你的上级。
- **登录**：`/user/login`，手机号 + 密码 + 图形验证码。登录页右上角可返回首页。
- **多语言**：首页右上角可切换简体 / 繁体 / 英文。第一次打开按站点默认语言显示，之后记住你的选择。

### 2. 浏览与竞拍

- **首页** `/`：轮播图、关于我们、精选商品。
- **分类** `/category`：按分类浏览。首页拍品列表和分类列表页都是上拉到底自动加载下一页，在原有内容后追加；底部文字仍可点击作为兜底。
- **搜索**、**成交记录** `/index/deals`。
- **商品详情** `/goods/detail?id=…`：显示编号（No:商品ID+10000）、起拍价、加价幅度、保证金、佣金比例、当前价、截拍倒计时、出价记录、卖家店铺（消费保证金、店铺星级、信誉分、粉丝数）。可收藏商品、关注店铺、咨询卖家（站内聊天）。佣金按后台基础设置的比例在成交后从成交价中扣除，卖家实收为成交价减佣金，比例为 0 时不收佣金。

**出价规则**

- 必须登录；不能给自己的商品出价；只能在开拍后、截拍前出价。
- 出价不得低于「当前价 + 加价幅度」，且必须按加价幅度整倍递增。
- 商品设有保证金时，首次出价会从可用余额冻结保证金（虚拟会员不冻结）。
- 截拍前若有人出价，按商品或系统设置的「延时秒数」自动延长截拍时间。
- 拍卖结束由系统自动结算：
  - 无人出价，或最高价低于卖家保留价 → **流拍**，所有保证金退回。
  - 否则最高价者**中标**，自动生成订单；其他人的保证金退回。

### 3. 订单（买家）

「我的订单」`/order/list`，状态：待付款、待发货、待收货、已完成、售后中。

1. **待付款**：中标后需在后台设定的小时数内付款。付款用余额，已冻结的保证金自动抵扣，不足部分从可用余额扣。需先填写收货地址。超时未付款系统自动取消订单，保证金按平台规则处理（没收 / 赔付卖家 / 退回买家）。
2. **待发货**：等待卖家发货。卖家长时间未发货，系统会自动催发货。
3. **待收货**：可查看物流单号，确认收货后订单完成。超过后台设定天数未确认，系统自动确认。
4. **已完成**：可申请售后，由平台处理。

### 4. 个人中心 `/user/center`

- **资料**：昵称、头像、修改密码、收货地址。
- **实名认证** `/user/auth`：上传身份证正反面，等待平台或代理审核。成为卖家、提现前必须完成实名认证。
- **钱包** `/user/wallet`：总资产（可用 + 冻结）、总收入、总支出、申请提现和充值入口；下方"资产明细"按时间倒序，页面滚到底部自动加载下一页。
  - **充值** `/user/recharge`：提交充值申请，平台审核通过后到账。
  - **提现** `/user/withdraw`：先在「提现账户」绑定支付宝 / 微信 / 银行卡 / USDT，再提交申请。受后台单笔最低 / 最高金额和手续费比例限制，平台审核后打款。
- **我的出价**、**收藏**、**关注店铺**、**足迹**、**站内消息**。
- **我的邀请** `/user/invite`：查看并复制自己的邀请码，查看已邀请的会员。

### 5. 卖家功能

- **申请入驻** `/seller/apply`：需先完成实名认证，填写店铺名称、企业资料（最多 5 张图）。后台开启「卖家开通审核」时需等待审核，关闭时立即生效。
- **发布商品** `/seller/goods_add`：标题、分类、详情、起拍价、加价幅度、保留价（可选）、保证金、截拍时间、是否精选、至少 4 张商品照片。后台开启「发布商品审核」时需先审核再上架。佣金比例由平台统一设置，卖家不能自定。
- **我的商品** `/seller/goods_list`：按状态筛选。竞拍中的商品可点击进入详情；流拍或下架的商品可设置新截拍时间「重新上架」；已成交的不能操作。
- **卖家订单** `/seller/orders`：买家付款后填写物流单号发货。成交后平台按佣金比例扣除佣金，剩余部分计入卖家余额。付款后长期不发货，系统每天催一次并扣 1 分信誉分。
- **店铺星级与信誉分**：个人中心的卖家中心入口显示自己的星级和信誉分，买家在商品页和店铺页也能看到。信誉分初始 100，由平台维护。
- **买家咨询** `/chat/list`：回复买家的站内咨询。

## 二、代理端

### 1. 什么是代理

代理是一个被主后台标记为「代理」的前台会员。代理的下级 = 注册时填写了该代理邀请码的会员（一级）。代理端只能看到、操作自己直接下级的数据，看不到其他人的。

### 2. 登录

- 地址 `/agent/login/index`，用前台会员的手机号和密码登录，需图形验证码。
- 不是代理的账号会提示「该账号不是代理账号」。
- 代理端与前台共用登录状态：前台已登录的代理进入 `/agent` 无需再次登录，在代理端退出也会同时退出前台。

### 3. 菜单与功能

| 菜单 | 页面 | 说明 |
|---|---|---|
| 团队概览 | 数据概览 | 下级人数、今日新增、成交金额等汇总 |
| 会员管理 | 我的会员 | 下级会员列表（只读），可按手机号 / 昵称 / 邀请码搜索，手机号已脱敏，不显示余额 |
| | 实名认证 | 审核下级会员提交的实名认证，通过或拒绝（填写原因） |
| | 卖家审核 | 审核下级会员的卖家入驻申请 |
| 产品管理 | 产品列表 | 下级卖家发布的商品，可查看、上下架、删除、修改开始 / 结束时间（竞拍中和待审核的商品） |
| | 产品审核 | 审核下级卖家发布的待审核商品 |
| 数据报表 | 团队业绩 | 按时间段查看下级成交数据（只读） |

页面头部显示代理自己的邀请码，分享给好友注册即成为下级。

## 三、主后台

登录地址 `/admin1314/login/index`。登录页有一个按钮可跳转到代理端登录。所有后台操作都会记入「操作日志」。

### 1. 仪表盘

系统概览：会员数、商品数、订单数、今日成交等统计。

### 2. 会员管理

**会员列表** `/admin1314/member/index`

- 搜索：手机号 / 昵称 / 邀请码，可按卖家、代理、状态、注册时间筛选。列表显示每个会员的上级。
- **添加会员**：手机号、密码、昵称、初始余额，可选「普通会员 / 虚拟会员」，可勾选「同时开通卖家权限」和「同时设为代理」。邀请码自动生成（8 位纯数字）。
  - 虚拟会员：选择后余额输入框默认填 100000，可改。这个余额永存，出价、付款后自动回补，不能充值提现，出价不冻结保证金，不记流水。用于活跃氛围。
- 每行操作：
  - **详情**：基本信息、上级会员（可点击跳转）、直接下级人数、店铺资料、提现账户、余额流水、出价记录。
  - **余额**：增减可用余额，需填备注，写入流水。
  - **重置密码**。
  - **改上级**：输入新上级的手机号 / 邀请码 / 会员 ID；留空则清空上级。不能设为自己或自己的下级。改上级会同时改变该会员归属哪个代理。
  - **私信**：给会员发站内信。
  - **禁用 / 启用**、**设为卖家 / 取消卖家**、**设为代理 / 取消代理**。

**实名认证** `/admin1314/member/auth`：审核会员提交的身份证资料，通过或拒绝。

**卖家审核** `/admin1314/member/seller`：审核入驻申请，查看营业执照，通过或拒绝；列表显示每个卖家的店铺星级和信誉分。在会员详情可编辑店铺资料（介绍、消保金、店铺星级、卖家信誉分、粉丝数）。

- **店铺星级**：0 到 5 星，前台以 ★ 显示。
- **卖家信誉分**：初始 100 分。买家付款后卖家长期未发货，定时任务每天提醒一次并扣 1 分，最低 0 分。买家在商品详情页和店铺页可以看到，卖家在个人中心可以看到，后台可随时手动修正（0 到 999）。

**咨询审核** `/admin1314/message/index`：查看买家与卖家的站内聊天记录，可修改或删除内容。

### 3. 商品管理

- **商品列表**：全部商品，按状态（待审核 / 拍卖中 / 已成交 / 流拍 / 已下架 / 审核拒绝）、分类、卖家筛选。
  - **发布商品**：后台代指定卖家发布，直接上架。
  - **修改时间**：竞拍中和待审核的商品可修改开始时间和结束时间。
  - **下架 / 上架**、**删除**、**详情**。
- **商品审核**：卖家发布的待审核商品，通过或拒绝（填写原因）。
- **分类管理**：分类名称（简 / 繁 / 英）、图片、排序、显示 / 隐藏。

### 4. 竞拍管理

**出价记录**：查看所有出价。**手动添加出价**：选择拍卖中的商品和一个会员，按加价规则录入一笔出价，常配合虚拟会员使用。

### 5. 订单管理

- **订单列表**：按订单状态、支付状态、时间筛选。可查看详情、代卖家发货（填物流单号）、手动完成、取消订单。
- **售后管理**：处理买家的售后申请，同意退款会扣回卖家的成交收入。

### 6. 数据报表

交易报表：按时间段统计成交额、佣金、订单数、新增会员等。

### 7. 财务管理

- **充值审核**：会员提交的充值申请，通过后到账，拒绝需填原因。
- **提现审核**：会员的提现申请，显示收款账户，通过后线下打款并标记，拒绝则余额退回。
- **余额流水**：全站资金变动记录，可按会员、类型筛选。

### 8. 系统设置

**基础设置** `/admin1314/setting/index`，分组如下：

| 分组 | 项目 | 说明 |
|---|---|---|
| 站点 | 站点名称、站点网址、Logo、客服电话 / QQ / 链接 | 前台展示 |
| 交易 | 平台佣金比例 | 成交后从成交价中扣除，卖家实收 = 成交价 − 佣金；0 为不收佣金 |
| | 提现手续费、单笔最低 / 最高金额 | 约束前台提现 |
| | 卖家开通审核、发布商品审核 | 开启则需人工审核 |
| | 竞拍默认延时（秒） | 截拍前出价自动延时 |
| 订单 | 待付款超时（小时） | 超时自动取消订单，0 不启用 |
| | 未付款订单的保证金处理 | 没收归平台 / 赔付卖家 / 退还买家 |
| | 自动确认收货天数 | 发货后 N 天自动完成，0 不启用 |
| | 未发货提醒天数 | 付款后 N 天未发货，每天催一次，0 不启用 |
| 内容 | 关于我们（简 / 繁 / 英）及背景图 | 首页「关于我们」板块和 `/about` 页面正文 |
| | 业务部门（简 / 繁 / 英） | `/about` 页面正文下方的部门卡片。每个部门一段，段间空一行；第一行部门名称，其余每行「岗位：姓名 姓名」，姓名可留空只显示岗位；为空则不显示该区块 |
| | 用户协议、隐私政策、发布协议（简 / 繁 / 英） | 前台各处协议 |

保存时只更新本次提交的字段，不会清空其他设置。

- **轮播管理**：首页轮播图片、链接、排序、启用状态。只有启用的才会在首页显示。
- **新闻管理**：公告 / 资讯发布。
- **管理员管理**：新增管理员、修改密码、删除。
- **操作日志**：所有后台操作记录，可清空。

## 四、运维与命令行

所有命令在项目根目录执行，PHP 使用 `D:\phpstudy_pro\Extensions\php\php8.0.2nts\php.exe`：

```bash
php think <命令>
```

### 定时任务（已注册到 Windows 任务计划程序）

| 命令 | 频率 | 作用 |
|---|---|---|
| `settle` | 每分钟 | 结算到期的拍卖：成交生成订单，流拍退保证金 |
| `order:timeout` | 每 5 分钟 | 取消超时未付款订单，按设置处理保证金，商品变为流拍 |
| `order:confirm` | 每小时 | 发货后超过设定天数自动确认收货 |
| `order:remind` | 每天 | 付款后超过设定天数未发货，给卖家发催发货站内信，并扣卖家信誉分 1 分 |

每个任务在 `runtime/` 下写心跳文件，日志在 `runtime/log/`。

### 手动命令

**初始化前台用户数据**（不可逆）

```bash
php think user:init
```

不加参数只演练，显示将清空的表和行数。确认后加 `--force` 真正执行，用 TRUNCATE 清空会员及其全部衍生数据（订单、出价、流水、充值提现等），保留商品和平台配置，并把商品重置为可竞拍状态。

**采集商品**

```bash
php think goods:collect --relist=7
```

从远端接口按 id 逐个采集商品，图片下载到 `public/uploads/collect/`。常用参数：`--start`、`--end`（默认 11 到 3362）、`--limit`（本次最多采几件）、`--update`（覆盖已采集项）、`--relist=N`（远端已结束的商品重新上架，截拍时间随机落在 1 到 N 天后）。重复执行自动跳过已采集项。日志 `runtime/log/goods_collect.log`。

### 配置文件

- `.env`：数据库连接、默认语言（`default_lang`）、调试开关、缓存驱动。上线前把 `APP_DEBUG` 改为 `false`。
- 缓存：`.env` 的 `[CACHE] DRIVER` 为 `redis` 时走 Redis，连接参数在 `[REDIS]` 段（主机、端口、密码、库编号、键前缀）。PHP 未加载 redis 扩展时自动退回 file 驱动，不会报错。缓存里只存登录防爆破计数和结算兜底锁，清空 Redis 不影响业务数据。
- `config/console.php`：命令注册。
- 语言包：`app/lang/zh-cn.php`、`zh-tw.php`、`en-us.php`。

### 上线检查清单

1. 修改 `.env` 数据库密码，关闭 `APP_DEBUG`。
2. 修改所有后台管理员的初始密码。
3. 在基础设置里填写站点名称、Logo、客服信息、佣金和提现规则。
4. 确认 4 个定时任务在任务计划程序中正常运行（查看 `runtime/` 心跳文件时间）。
5. 至少创建一个卖家会员，否则后台无法代发商品。
