1. 平台概述

本平台是一个在线拍卖系统，会员可以作为买家参与竞拍，也可以申请成为卖家发布拍品。系统由三个端组成：面向会员的前台、面向代理的代理端、面向平台运营人员的主后台。

1.1 三个端与入口地址

端入口地址登录账号
前台会员端/前台会员账号，手机号 + 密码。电脑浏览器打开时按手机版样式居中显示一列，操作方式与手机一致
代理端/agent/login/index前台会员账号，且该会员已在主后台被设为「代理」
主后台/admin1314/login/index管理员账号，在后台「管理员管理」中维护
三个端的登录页都有图形验证码。连续输错密码会被临时锁定，等几分钟后再试即可。

1.2 角色说明

买家注册即为买家。可以浏览、收藏、出价、付款、收货、申请售后，与卖家和平台客服聊天。
卖家完成实名认证后申请入驻，审核通过即为卖家。可以发布拍品、发货、查看店铺数据，成交款扣除佣金后进入余额。
代理被主后台标记为「代理」的会员。通过自己的邀请码发展下级，在代理端管理这些下级的实名、入驻和拍品审核。
管理员主后台操作人员，负责审核、财务、客服和系统设置。所有操作都会记入操作日志。

上级关系：会员注册时填写谁的邀请码，谁就是这个会员的上级。上级如果是代理，这个会员就归该代理管理。邀请码是 6 位纯数字，在个人中心「我的邀请」查看。

1.3 一次完整的交易流程

① 发布卖家发布拍品，设置起拍价、加价幅度、保证金和截拍时间
② 审核上架后台或代理审核通过后进入「拍卖中」（可设为免审核）
③ 竞拍买家出价，首次出价冻结保证金；临近截拍出价自动延时
④ 结算截拍后系统自动结算，最高价者中标生成订单，其余人保证金退回
⑤ 付款买家在限定时间内用余额付款，保证金自动抵扣
⑥ 发货卖家填写快递公司和单号发货
⑦ 收货买家确认收货，或到期系统自动确认
⑧ 卖家收款买家付款时成交价扣除平台佣金后即计入卖家余额，卖家可申请提现

2. 前台会员端

2.1 注册与登录

注册 /user/register

  • 填写手机号、密码、邀请码。
  • 邀请码是否必填由后台开关决定：开启时输入框标注「必须填写」，不填不能注册；关闭时标注「如无可不填」，不填则没有上级。只要填了就会校验是否存在。
  • 注册页底部可查看《用户协议》和《隐私政策》，协议页顶部可在两份协议间切换。

登录 /user/login

  • 手机号 + 密码 + 图形验证码。
  • 登录页右上角可以返回首页；未登录也可以浏览拍品，出价、收藏等操作会跳转到登录页。

多语言

首页右上角可切换简体中文 / 繁体中文 / English。第一次打开按站点默认语言显示，之后记住你的选择。协议、关于我们等内容如果后台填写了对应语言，会跟随切换。

2.3 商品详情与出价

商品详情页 /goods/detail?id=… 显示：拍品编号（No: 商品 ID + 10000）、图片轮播、起拍价、加价幅度、保证金、当前价、截拍倒计时、出价记录、佣金说明，以及卖家店铺卡片（店铺星级、信誉分、消费保证金、粉丝数）。可以收藏拍品、关注店铺、咨询卖家。

佣金平台按后台设定的比例在成交后从成交价中扣除。比例大于 0 时详情页显示绿色「有」，等于 0 时显示红色「无」。买家支付的金额不变，佣金由卖家承担。
保证金拍品设有保证金时，首次出价会从可用余额冻结对应金额，未中标自动退回，中标后抵扣货款。

出价规则

  1. 必须登录；不能给自己的拍品出价；只能在开拍后、截拍前出价。
  2. 出价不得低于「当前价 + 加价幅度」，并且必须是加价幅度的整数倍递增。
  3. 可用余额不足以冻结保证金时无法出价，请先充值。
  4. 截拍前若有人出价，按拍品或系统设置的「延时秒数」自动延长截拍时间，防止最后一秒截胡。

截拍与结算

  • 无人出价，或最高价低于卖家设置的保留价：流拍，所有保证金退回，卖家可重新上架。
  • 否则最高出价者中标，系统自动生成订单，其他出价者的保证金退回。

2.4 买家订单

「我的订单」/order/list 按状态分为：待付款、待发货、待收货、已完成、售后中。

状态你要做什么系统会做什么
待付款先填写收货地址，然后用余额付款。已冻结的保证金自动抵扣，不足部分从可用余额扣除。也可以主动取消订单超过平台设定的小时数未付款，自动取消订单，保证金按平台规则处理（没收 / 赔付卖家 / 退回买家）
待发货等待卖家发货卖家长期不发货，系统每天催一次并扣卖家信誉分
待收货查看物流单号，收到货后点「确认收货」超过平台设定天数未确认，自动确认收货
已完成如有问题可申请售后，填写原因平台处理售后，同意退款时款项退回余额

2.6 钱包、充值与提现

我的钱包 /user/wallet

顶部卡片显示总资产（可用 + 冻结）、总收入、总支出，并有「充值」「提现」按钮。下方「资产明细」按时间倒序列出每一笔变动，滚到底部自动加载更多。平台手动调整余额的记录会标注「后台调整」及备注。

充值 /user/recharge

  1. 输入充值金额，点击「提交充值申请」。
  2. 点击「充值方式」一行进入在线客服，联系客服完成转账。
  3. 平台审核通过后金额自动到账；被拒绝会显示拒绝理由。右上角图标可查看充值记录。
同一时间只能有一笔充值申请在审核中，审核完成后才能再次提交。

提现 /user/withdraw

  1. 先在「提现账户」绑定收款方式：支付宝、微信、银行卡或 USDT。
  2. 输入提现金额提交申请。金额受平台设定的单笔最低 / 最高限制，并按比例扣除手续费，页面会显示实际到账金额。
  3. 提交后申请金额立即从可用余额扣除，平台审核通过后线下打款；拒绝则退回可用余额。可在「提现记录」查看进度。

2.7 消息与在线客服

  • 咨询卖家：商品详情页点「咨询」进入与该卖家的聊天，卖家在「消息」中回复。
  • 联系客服 /service/index：与平台管理员聊天，支持文字和图片（点输入框左侧图标选图）。管理员也可能主动发起会话。平台若配置了客服链接，聊天页右上角有「其他联系方式」。
  • 发送频率：聊天和客服共用限制，同一会员 3 秒内只能发一条，过快会提示「发送太频繁，请 3 秒后再试」。
  • 新消息提示：个人中心的「站内信」「消息」「联系客服」有未读时会变红、显示数字角标和「有新消息」。页面停留时每 60 秒自动查询一次，切回页面时立即查询，无需刷新。

2.8 卖家功能

申请入驻 /seller/apply

需先完成实名认证。填写店铺名称、店铺介绍、企业资料图片（最多 5 张）。平台开启「卖家开通审核」时需等待平台或代理审核，关闭时立即生效。

卖家面板

审核通过的卖家登录后，前台任意页面右上方都有一个悬浮的圆形按钮。按住可以拖到任意位置，松手自动贴边，位置会记住。轻点按钮从左侧滑出卖家面板：

  • 头像、店铺名称、退出登录。
  • 官方验证：企业认证通过后显示绿色勾和「企业认证」。
  • 店铺星级、信誉分、店铺收藏数。
  • 入口：首页、店铺首页、店铺商品、我的订单、我的钱包、店铺设置（修改资料页）。

普通会员、未登录或退出登录后不显示该按钮。

发布拍品 /seller/goods_add

字段说明
标题、分类、详情详情支持多段文字
起拍价、加价幅度买家每次出价必须按加价幅度整倍递增
保留价（可选）最高出价低于保留价时流拍，买家看不到保留价
保证金买家首次出价时冻结的金额，0 表示不需要

发布前需勾选同意《发布协议》。平台开启「发布商品审核」时需先审核再上架。佣金比例由平台统一设置，卖家不能自定。

我的商品 /seller/goods_list

按状态筛选：待审核、拍卖中、已成交、流拍、已下架、审核拒绝。拍卖中的可进入详情；流拍或下架的可设置新的截拍时间「重新上架」；已成交的不能操作。

卖家订单 /seller/orders

买家付款后，点订单上的「发货」，在弹出的表单中填写快递公司和快递单号后确认。买家付款时，成交价扣除平台佣金后即计入卖家可用余额，钱包明细可查；买家确认收货（或系统自动确认）后订单完成。若买家售后退款成功，这笔收入会从卖家余额扣回。

店铺星级与信誉分

  • 店铺星级：0 到 5 星，由平台设置，买家在商品页和店铺页能看到。
  • 信誉分：初始 100 分。买家付款后长期不发货，系统每天催一次并扣 1 分，最低 0 分。平台可手动修正。

3. 代理端

3.1 什么是代理

代理是一个被主后台标记为「代理」的前台会员。代理的下级是注册时填写了该代理邀请码的会员（直接下级）。代理端只能看到和操作自己直接下级的数据，看不到其他会员。

主后台可以修改任何会员的上级，改上级后该会员会立即归到新上级对应的代理名下。

3.2 登录

  • 地址 /agent/login/index，用前台会员的手机号和密码登录，需图形验证码。
  • 不是代理的账号会提示「该账号不是代理账号」。
  • 代理端与前台共用登录状态：前台已登录的代理直接访问 /agent 无需再次登录，在代理端退出也会同时退出前台。
  • 页面头部显示代理自己的邀请码，分享给好友注册即成为下级。

4. 主后台

4.1 登录与界面

登录地址 /admin1314/login/index，管理员账号 + 密码 + 图形验证码。登录页有按钮可跳转到代理端登录。

谷歌验证码（可选）：基础设置中开启「后台登录谷歌验证码」后，登录还需输入 Google Authenticator、Microsoft Authenticator 等验证器 App 上的 6 位动态码。尚未绑定的管理员登录后会被引导到「系统设置 › 谷歌验证」页扫码绑定，绑定完成前不能进入其他页面。更换手机前先在该页用当前动态码解绑；手机丢失时由超级管理员在「管理员管理」中点「重置谷歌验证」，对方下次登录重新绑定。

左侧是菜单栏，「在线客服」菜单上的红色数字是待回复的客服消息数，每 30 秒自动刷新。右上角显示当前管理员并可退出。所有操作都会记入「操作日志」。

4.2 会员管理

会员列表 /admin1314/member/index

添加会员：手机号、密码、昵称、初始余额，可选「普通会员 / 虚拟会员」，可勾选「同时开通卖家权限」「同时设为代理」。邀请码自动生成。

虚拟会员：选择后余额输入框默认填 100000，可修改。虚拟会员的余额永存，出价、付款后自动回补，不能充值提现，出价不冻结保证金，不记流水，用于活跃竞拍氛围。配合「竞拍管理 › 手动添加出价」使用。

查看会员上传的身份证正反面，通过或拒绝（填写原因），结果以站内信通知会员。

卖家审核 /admin1314/member/seller

审核入驻申请，查看企业资料，通过或拒绝。列表显示每个卖家的店铺星级和信誉分。在会员详情可编辑店铺资料：店铺介绍、消费保证金、店铺星级（0 到 5）、卖家信誉分（0 到 999）、粉丝数。

咨询审核 /admin1314/message/index

查看买家与卖家之间的站内聊天记录，可修改或删除违规内容。

4.3 在线客服工作台 /admin1314/service/index

  • 会话列表（左侧）：按最近消息排序，显示每个会员的未回复数，可勾选「只看未回复」。
  • 对话窗口（右侧）：显示往来消息，支持文字和图片回复，Enter 发送。
  • 主动发起：搜索框可按手机号 / 昵称 / 店铺名搜到所有会员。已聊过的排在前面，没聊过的标记「发起」，点击后直接输入内容即可开启会话，会员在个人中心「联系客服」处收到未读提醒。
  • 任何管理员都可以回复，记录中会记下回复人。

4.4 商品管理与竞拍管理

商品列表 /admin1314/goods/index

全部拍品，按状态（待审核 / 拍卖中 / 已成交 / 流拍 / 已下架 / 审核拒绝）、分类、卖家筛选。

  • 发布商品：后台代指定卖家发布，直接上架。系统里至少要有一个卖家会员。
  • 修改时间：拍卖中和待审核的拍品可修改开始时间和结束时间。
  • 下架 / 上架、删除、详情。

商品审核 /admin1314/goods/check

卖家发布的待审核拍品，通过后进入拍卖中，拒绝需填写原因。

分类管理 /admin1314/category/index

分类名称（简 / 繁 / 英）、分类图片、排序、显示 / 隐藏。首页宫格显示前 7 个。

出价记录 /admin1314/bid/index

查看所有出价记录。手动添加出价：选择一个拍卖中的拍品和一个会员，按加价规则录入一笔出价，通常配合虚拟会员使用，出价后同样触发延时规则。

4.5 订单管理

订单列表 /admin1314/order/index

按订单状态、支付状态、时间筛选。可查看详情、代卖家发货（填物流单号）、手动完成订单、取消订单。

处理买家提交的售后申请。同意退款时款项退回买家余额，并从卖家的成交收入中扣回；拒绝需填写原因。

5. 常见问题

问题处理方法
注册时提示「邀请码不存在」邀请码是 6 位纯数字，请向邀请人核对。平台关闭邀请码开关后可以不填
登录提示锁定连续输错密码触发保护，等几分钟后再试。忘记密码可联系客服，由后台重置
出价提示「余额不足」拍品设有保证金，可用余额不够冻结。请先充值
出价被拒绝「不符合加价幅度」出价必须不低于当前价 + 加价幅度，且为加价幅度的整数倍
中标了但付不了款先在个人中心添加收货地址；确认可用余额加已冻结保证金足够支付
付款后卖家一直不发货系统会按设置每天催卖家并扣信誉分，也可以联系在线客服介入
提现被拒绝钱包「提现记录」查看拒绝理由，金额已退回可用余额，核对收款账户后重新提交
无法申请入驻 / 提现需先完成实名认证并等待审核通过
发布拍品后前台看不到平台开启了发布审核，需等平台或代理审核通过；也可能开拍时间未到
看不到卖家悬浮按钮只有审核通过的卖家登录后才显示；按钮可拖动，可能被拖到了屏幕边缘
卖家点「发货」没有反应发货需要在弹出的表单里填写快递公司和快递单号，两项都不能为空
后台改了设置前台没变化确认已点「保存全部设置」；前台页面刷新一次即可
拍品到期没有自动结算稍等片刻刷新页面，系统会自动补结算；长时间未结算请联系平台技术人员
